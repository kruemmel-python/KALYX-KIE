KALYX-KIE v1.0 Final

Prompt Authoring + Governance Runtime

KALYX-KIE verbindet Prompt-Erstellung, Contract-Synthesis, LLM-Response-Validierung, Strict Dispatch Gate, Workflow-Policy, Sandbox-Ausführung und Audit-Trail.

Prompt-Pack

Aus Profil und Ziel entsteht ein versionierbares Prompt- und Contract-Paket.

Validation

LLM-Antworten werden als KRESP01 geprüft und nur bei accepted=true dispatcht.

Audit

KAUDIT01, KDISPATCH01 und KWORKFLOW01 dokumentieren den vollständigen Lauf.

Flow

1 ProfileKPROFILE01
2 PackKPROMPTPACK
3 EnvelopeKIE01
4 ResponseKRESP01
5 AuditKAUDIT/KDISPATCH

Quick Start

.\scripts\run_kalyx_v1_0_final_offline_reference.ps1
.\scripts\run_kalyx_v1_0_final_lmstudio_live.ps1
.\scripts\run_kalyx_v1_0_final_version_check.ps1
Erwartung: 130/130 Tests grün, KRESP accepted, Dispatch sandbox_executed, KWORKFLOW01 status ok.

KALYX vs. Prompty

Prompty macht Prompt-Dateien ausführbar. KALYX macht Prompt-basierte LLM-Interaktionen zusätzlich kontrollierbar, validierbar, dispatchbar und auditierbar.

Prompty  = Prompt-Datei + Runtime
KALYX-KIE = Prompt + Contract + Validation + Dispatch + Audit
