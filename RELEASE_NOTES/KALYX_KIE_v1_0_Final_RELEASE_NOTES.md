# KALYX-KIE v1.0 Final Release Notes

v1.0 Final ist der stabile Schnitt nach RC2. Es werden keine neuen Runtime-Features gegenüber RC2 eingeführt. Ziel ist ein final benutzbarer, reproduzierbarer KALYX-KIE-Stand mit eingefrorener CLI-/Schema-Oberfläche.

## Finalisierung

- Version auf `1.0-kie-v1.0-final` gesetzt.
- Final-Manifest ergänzt.
- Final-Quickstart, Testmatrix, Known-Issues und Schema-Freeze ergänzt.
- Offizielle Final-Runbooks ergänzt.
- CMake-Smoke-Checks auf Final-Dokumente aktualisiert.

## Eingefrorene Runtime-Pfade

- Custom KPROFILE01 Loader
- Prompt-Pack-Erzeugung
- KIE01 Envelope-Erzeugung
- LM-Studio-Bridge
- KRESP01 Validation
- Strict Dispatch Gate
- Workflow Policy Engine
- Sandbox Dispatch
- KAUDIT01 / KDISPATCH01 / KWORKFLOW01 Audit-Artefakte

## Release-Regel

Nach v1.0 Final sollten Änderungen entweder als Patch `v1.0.x` oder als bewusst geplante neue Minor-Version erfolgen.
