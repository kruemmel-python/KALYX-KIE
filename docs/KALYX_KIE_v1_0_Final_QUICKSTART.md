# KALYX-KIE v1.0 Final Quickstart

Dieser Quickstart zeigt den offiziellen Final-Pfad.

## Offline

```powershell
.\scriptsun_kalyx_v1_0_final_offline_reference.ps1
```

## LM Studio

LM Studio starten, Modell laden, dann:

```powershell
.\scriptsun_kalyx_v1_0_final_lmstudio_live.ps1
```

## Erwartung

- Build erfolgreich
- CTest grün
- Prompt-Pack erzeugt
- Envelope erzeugt
- KRESP01 validiert
- KDISPATCH01 `sandbox_executed`
- KWORKFLOW01 `status=ok`
